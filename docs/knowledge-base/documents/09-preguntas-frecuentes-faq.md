# XpertIA+ — Preguntas Frecuentes (FAQs Oficiales)

### 1. ¿Cuánto tiempo toma un proyecto promedio?
Depende del alcance del proyecto. Durante la etapa inicial de Descubrimiento entregamos un cronograma claro con fechas concretas. Trabajamos mediante entregas cortas quincenales para que veas avances reales cada dos semanas, en lugar de esperar hasta el final del desarrollo.

### 2. ¿Trabajan con empresas de cualquier tamaño?
Sí. Adaptamos la solución y el alcance a la realidad y presupuesto de cada cliente: desde una consultoría puntual de arquitectura o auditoría de seguridad para una startup, hasta el desarrollo de un sistema ERP/CRM completo para corporaciones o plataformas Moodle/OJS para universidades.

### 3. ¿Qué pasa después de que el proyecto se lanza a producción?
No desaparecemos tras el lanzamiento. Todos nuestros proyectos incluyen garantía técnica y ofrecemos planes de soporte y acompañamiento post-lanzamiento para resolver dudas, aplicar mejoras, realizar mantenimientos preventivos y asegurar alta disponibilidad.

### 4. ¿Cómo funciona la primera consultoría?
Es una conversación técnica y estratégica completamente gratuita y sin compromiso de contratación. En ella nos cuentas el problema o idea de tu negocio, evaluamos la viabilidad tecnológica y te orientamos sobre las mejores alternativas para resolverlo.

### 5. ¿Cómo cotizan un proyecto?
Primero definimos el alcance real y objetivos durante la fase de Descubrimiento. Con base en esa información, presentamos una propuesta formal con precio cerrado, desglose por etapas y entregables claros, sin cobros ocultos ni sorpresas durante el camino.

### 6. ¿El cliente es dueño del código fuente y de los sistemas desarrollados?
Totalmente. Al finalizar el proyecto y cumplirse los acuerdos contractuales, se entregan todos los repositorios, código fuente, documentación técnica y accesos de administración al cliente. No cobramos licencias propietarias por el código desarrollado a medida.
