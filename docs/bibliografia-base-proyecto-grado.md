# Bibliografia base para el proyecto de grado

Proyecto tentativo: Desarrollo de un sistema CRM conversacional multiempresa con integracion a WhatsApp Cloud API para la gestion de clientes y oportunidades comerciales.

Fecha de primera verificacion: 17 de mayo de 2026.

## Criterio de seleccion

Las referencias se seleccionan para sostener cuatro partes del documento:

- Fundamentos de CRM, gestion comercial y relacion con clientes.
- Ingenieria de software, requisitos, arquitectura y calidad.
- Metodologia de desarrollo y organizacion del trabajo.
- Documentacion tecnica oficial de las tecnologias usadas en el sistema.

## Uso por seccion del perfil

### Antecedentes

Fuentes recomendadas:

- Prior, Buttle y Maklan (2024).
- Payne (2006).
- Documentacion oficial de Meta sobre WhatsApp Cloud API.

Enfoque:

- Evolucion del CRM desde la gestion de datos de clientes hasta plataformas integradas con canales conversacionales.
- Necesidad de centralizar informacion comercial, contactos, conversaciones y oportunidades.

### Planteamiento del problema

Fuentes recomendadas:

- Prior, Buttle y Maklan (2024).
- Payne (2006).
- OWASP API Security Top 10 (2023), si el problema incluye seguridad e integracion con APIs.

Enfoque:

- Perdida de trazabilidad comercial.
- Informacion de clientes dispersa.
- Falta de seguimiento de oportunidades.
- Riesgos de gestionar conversaciones por canales no integrados.
